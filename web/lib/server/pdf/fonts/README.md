STIX Two Math is bundled for MathML in exported PDFs so mathematical glyphs do not depend on server fonts. It is used only by the PDF renderer; the website still uses its existing math rendering.

Source: https://github.com/google/fonts/tree/main/ofl/stixtwomath
File: STIXTwoMath-Regular.ttf, retrieved 2026-10-27.

JetBrains Mono is the editor's named monospace fallback. The PDF renderer embeds it for code blocks instead of relying on OS fonts (serverless Linux has no monospace font installed).

Source: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
File: JetBrainsMono[wght].ttf, saved as JetBrainsMono.ttf, retrieved 2026-10-27.
License: SIL Open Font License 1.1, included in JetBrainsMono-OFL.txt.
